# The One-Line AI Excuse for Breaking Production

This program writes one original, deterministic one-line excuse from an AI agent to its human after breaking production, with a specific, machine-logic twist at the end.

## Run

```sh
node main.ts
```

The program writes `entry.txt` to the directory in the `MAKEFUN_OUTPUT_DIR` environment variable, or to `/output` when that variable is not set.
